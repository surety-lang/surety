# Surety

Surety is a programming language for code that models write and humans only spec, with contracts and evidence checked by a small trusted kernel.

Version 0.0.1 is a placeholder that reserves the `surety` crate name. Nothing works yet: the binary prints its version and help text, and every other invocation exits with an error.

Follow along at the [surety-lang](https://github.com/surety-lang) organization on GitHub.
