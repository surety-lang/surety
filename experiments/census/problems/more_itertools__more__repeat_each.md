more_itertools.more.repeat_each (from more-itertools 11.2.1)

Signature, in words: `repeat_each` takes the required argument `iterable`; the optional argument `n` (default `2`).

The docstring:

Repeat each element in *iterable* *n* times.

>>> list(repeat_each('ABC', 3))
['A', 'A', 'A', 'B', 'B', 'B', 'C', 'C', 'C']
