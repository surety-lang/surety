toolz.itertoolz.frequencies (from toolz 1.2.0)

Signature, in words: `frequencies` takes the required argument `seq`.

The docstring:

Find number of occurrences of each value in seq

>>> frequencies(['cat', 'cat', 'ox', 'pig', 'pig', 'cat'])  #doctest: +SKIP
{'cat': 3, 'ox': 1, 'pig': 2}
